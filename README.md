# Drum 808

浏览器里的节奏机。八种鼓声由 Web Audio 实时合成，打开页面就能写节奏。第一版采用原生 DOM 与 TypeScript，不需要后端，不加载采样、网络字体或第三方运行时。

## 本地运行

需要 Node.js 22.12+ 与 npm 10。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。首次点击播放或步进键时启用声音，建议先降低设备音量。

```sh
npm test          # Vitest 数据模型、Swing、模拟音频时钟
npm run test:e2e # Chromium 页面交互与真实离线音频渲染
npm run build    # 严格 TypeScript 检查与静态构建
npm run preview  # 预览 dist/ 构建结果
```

端到端检查需要 Playwright 对应的 Chromium；机器没有浏览器时先运行 `npx playwright install chromium`。构建产物在 `dist/`，可托管于静态服务器的根目录或子目录。

## 功能与操作

- 八声部 × 十六步：底鼓 BD、军鼓 SD、闭镲 CH、开镲 OH、拍手 CP、低嗵鼓 LT、边击 RS、牛铃 CB。
- 点击在关闭和普通力度间切换；右键或 Alt / Option 点击，将已开启的步进按弱音 → 普通 → 重音 → 弱音循环。手机长按约 400 毫秒完成同一操作。
- 鼠标按住并扫过网格，以第一个格子的新状态绘制；停止时编辑会试听相应鼓声。触屏滑动用于浏览网格，短点编辑，长按调整力度。
- 点击播放 / 停止，或在非输入区按空格。聚焦步进按钮后，可按 Enter 编辑。
- BPM 60–200，Swing 50%–75%。滑块与数值输入可用方向键调整。50% 为平直节奏；Swing 只推迟成对细分中的后一步，保持整小节时长。
- 每轨 M 静音、S 独奏。点击声部名称选择并在停止时试听，在侧栏调整该声部的音量；底鼓与开镲可调衰减，军鼓可调响弦亮度。默认选中底鼓，重新加载后恢复该选择；混音参数照常保存。静音优先于独奏，多个声部可同时独奏。
- 主音量、压缩限幅与软峰值保护；闭镲和新的开镲会在 8 毫秒内截断前一个开镲。
- 五套原创预设：四拍地板（Four on the Floor）、街角鼓点（Boom Bap）、车库现场（Rock）、电气脉冲（Electro）、午夜切分（含军鼓弱音的摇摆律动）。另有清空按钮。
- 节奏、BPM、Swing、主音量与混音设置自动保存到当前浏览器；损坏或旧格式数据回退到默认节奏。存储受限时可继续使用，并显示无法保存的提示。
- 复古暖色面板，以网格为中心，播放控制位于紧凑顶栏，预设与所选声部的控制位于侧栏。关闭步进为中性深色，拍首略亮；开启步进用各自的声部色。弱音为居中色块，普通为整格柔光，重音更亮并带高光条，灰度下也能辨别。经典四色只保留为列号下方的分组细条。
- 手机顶栏分为两行，侧栏移到网格下方。网格横向滚动，声部名称固定在左侧；手机步进触摸目标为 36 × 44 像素。支持减少动态效果偏好，无光晕脉冲动画。

## 项目结构

```text
src/
  audio/voices.ts       八种合成声部，可用于实时和离线音频上下文
  audio/engine.ts       用户手势解锁、混音、限幅、开镲截断与停止清理
  sequencer/pattern.ts  力度数据、编辑、预设与版本化存储
  sequencer/clock.ts    Swing 纯函数、前瞻时钟、Worker 唤醒及降级
  ui/panel.ts           原生 DOM 面板、鼠标 / 键盘 / 触屏输入
  main.ts              状态、音频、播放队列与本地存储的连接
  style.css            复古面板与响应式样式
tests/
  *.test.ts            数据与时钟单元测试
  e2e/                 Chromium 交互、截图与离线音频检查
docs/how-it-works.md    合成与定时原理
```

Pattern 的 `stepsPerBar` 决定步数，`tracks[].steps` 保存整数力度：0 关闭、1 弱音、2 普通、3 重音。时钟与网格按数据生成，支持 12 / 16 / 24 等偶数细分；本版只提供十六步的预设与界面入口。为以后增加三连音网格、练习模式和离线导出保留数据基础，目前不包含这些功能。

预调度窗口为 110 毫秒，参数与编辑会在接下来的未调度音符中生效。长时间后台暂停后会跳过错过的步进，不补播一串迟到的音符。没有联网、统计或云端保存。

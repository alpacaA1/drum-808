# Drum 808

浏览器里的节奏机。八种鼓声由 Web Audio 实时合成，打开页面就能写节奏。第一版采用原生 DOM 与 TypeScript，不需要后端，不加载采样、网络字体或第三方运行时。

## 本地运行

需要 Node.js 22.12+ 与 npm 10。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。首次点击播放或步进键时启用声音，建议先降低设备音量。

```sh
npm test          # Vitest 数据模型、Swing、模拟音频时钟
npm run test:e2e # Chromium 页面交互与真实离线音频渲染
npm run build    # 严格 TypeScript 检查与静态构建
npm run preview  # 预览 dist/ 构建结果
```

端到端检查需要 Playwright 对应的 Chromium；机器没有浏览器时先运行 `npx playwright install chromium`。构建产物在 `dist/`，可托管于静态服务器的根目录或子目录。

## 功能与操作

- 八声部 × 十六步：底鼓 BD、军鼓 SD、闭镲 CH、开镲 OH、拍手 CP、低嗵鼓 LT、边击 RS、牛铃 CB。
- 点击在关闭和普通力度间切换；右键或 Alt / Option 点击，将已开启的步进按弱音 → 普通 → 重音 → 弱音循环。手机长按约 400 毫秒完成同一操作。
- 鼠标按住并扫过网格，以第一个格子的新状态绘制；停止时编辑会试听相应鼓声。触屏滑动用于浏览网格，短点编辑，长按调整力度。
- 点击播放 / 停止，或在非输入区按空格。聚焦步进按钮后，可按 Enter 编辑。
- BPM 60–200，Swing 50%–75%。BPM、Swing、主音量及所选声部的音量、音色均用旋钮调整，BPM 也保留数值输入。50% 为平直节奏；Swing 只推迟成对细分中的后一步，保持整小节时长。
- 旋钮向上拖动增大，约 200 像素走完整个量程；按住 Shift 以十分之一速度精调。滚轮只在旋钮上方调值，其他区域正常滚动页面。聚焦后，方向键每次 1，PageUp / PageDown 每次 10，Home / End 到最小 / 最大值。双击恢复默认：BPM 128、Swing 50%、主音量 75%、声部音量 80%、音色 50%。旋钮提供含单位的无障碍读数。
- 每轨 M 静音、S 独奏。点击声部名称选择并在停止时试听，在侧栏调整该声部的音量；底鼓与开镲可调衰减，军鼓可调响弦亮度。默认选中底鼓，重新加载后恢复该选择；混音参数照常保存。静音优先于独奏，多个声部可同时独奏。
- 主音量、压缩限幅与软峰值保护；闭镲和新的开镲会在 8 毫秒内截断前一个开镲。
- 五套原创预设：四拍地板（Four on the Floor）、街角鼓点（Boom Bap）、车库现场（Rock）、电气脉冲（Electro）、午夜切分（含军鼓弱音的摇摆律动）。另有清空按钮。
- 工作会话（节奏、BPM、Swing、主音量与混音）自动保存在当前浏览器。「我的节奏」可另存为命名条目，最多 200 段；留空自动命名，重名自动追加编号。「保存」覆盖当前载入的条目，「另存为…」新增条目。名称支持 1–40 个字，可在列表内改名、确认删除。
- 步进、BPM、Swing 或混音改变后显示「已修改」；载入条目、选择预设、清空或切换网格前会提醒先保存、放弃或取消。主音量是全局试听设置，不属于节奏库条目，载入节奏时保持不变。
- 每条节奏可「导出」为 JSON，「导出全部」备份整个库；「导入」支持多选 JSON，只新增条目，不覆盖已有内容。同一个文件重复导入会新增副本并追加名称编号。浏览器存储不可用或已满时，内容保留在本页并显示提示，请在刷新前导出备份。浏览器库原始数据无法解析时会先备份到 `drum808.library.corrupt.<时间戳>`，备份失败则不覆盖原数据。
- 复古暖色面板，以网格为中心，播放控制位于紧凑顶栏，预设与所选声部的控制位于侧栏。关闭步进为中性深色，拍首略亮；开启步进用各自的声部色。弱音为居中色块，普通为整格柔光，重音更亮并带高光条，灰度下也能辨别。经典四色只保留为列号下方的分组细条。
- 实体按键式倒角、下沿阴影与按压反馈；播放键及 M / S 带独立指示灯。列号上方的红色 LED 随音频时钟推进，并以整列浅色光带标记当前步；停止后熄灭。
- 手机顶栏保持两行，侧栏移到网格下方。网格横向滚动，声部列固定在左侧；480 像素及以下显示颜色点与缩写，M / S 上下排列，中文名称保留在无障碍标签中。390 像素宽时无需滚动即可完整看到至少六步；步进目标为 32 × 56 像素，M / S 为 28 × 28 像素。支持减少动态效果偏好，无光晕脉冲动画。

## 项目结构

```text
src/
  audio/voices.ts       八种合成声部，可用于实时和离线音频上下文
  audio/engine.ts       用户手势解锁、混音、限幅、开镲截断与停止清理
  sequencer/pattern.ts  力度数据、编辑、预设与版本化存储
  sequencer/library.ts  节奏库校验、名称、导入导出与存储保护
  sequencer/clock.ts    Swing 纯函数、前瞻时钟、Worker 唤醒及降级
  ui/panel.ts           原生 DOM 面板、鼠标 / 键盘 / 触屏输入
  ui/knob.ts            可复用旋钮、捕获拖动与无障碍键盘操作
  ui/library.ts         节奏库列表与行内编辑、确认
  main.ts              状态、音频、播放队列与本地存储的连接
  style.css            复古面板与响应式样式
tests/
  *.test.ts            数据与时钟单元测试
  e2e/                 Chromium 交互、截图与离线音频检查
docs/how-it-works.md    合成与定时原理
```

Pattern 的 `stepsPerBar` 决定步数，`tracks[].steps` 保存整数力度：0 关闭、1 弱音、2 普通、3 重音。界面支持 12 / 16 / 24 步网格及三连音预设。

## 节奏文件格式

单条导出为 `{ "type": "drum808-rhythm", "version": 1, "name": "名称", "rhythm": { "pattern": {}, "bpm": 128, "swing": 50, "mixer": {} } }`；`pattern` 和 `mixer` 为完整的八轨数据。整库导出为 `{ "type": "drum808-library", "version": 1, "items": [{ "name": "名称", "createdAt": 0, "updatedAt": 0, "rhythm": {} }] }`，时间为毫秒时间戳，`rhythm` 与单条格式相同。导出文件不包含主音量或浏览器内部 ID。

导入也接受旧工作会话 `{ "version": 1, "pattern": {}, "bpm": 128, "swing": 50, "master": 0.75, "mixer": {} }`，以文件名（去扩展名，最多 40 个字）命名，主音量不导入。每个文件报告新增和无效项数量；整库内无效条目单独跳过。导出文件名为 `drum808-名称-YYYYMMDD.json` 或 `drum808-library-YYYYMMDD.json`，保留中文并去除路径等非法字符。旧版 `drum808.session.v1` 工作会话继续兼容，首次载入显示「未命名」，编辑后才提示未保存。

预调度窗口为 110 毫秒，参数与编辑会在接下来的未调度音符中生效。长时间后台暂停后会跳过错过的步进，不补播一串迟到的音符。没有联网、统计或云端保存。
